# FP&A Financial Performance Dashboard

## Project Overview

This project presents an FP&A financial performance dashboard developed in Power BI to monitor the financial performance of a fictional company.

The objective is to compare actual financial results against budget, identify performance gaps, and provide management with a clear view of profitability and cost evolution.

## Dashboard Preview

The dashboard provides a consolidated view of financial performance across the year.

## Key KPIs

- Revenue: €4.182M
- Budget Revenue: €4.070M
- Revenue Variance: +2.73%
- EBITDA: €1.449M
- EBITDA Margin: 34.65%

## Financial Analysis

The dashboard focuses on:

- Revenue vs Budget
- Revenue Variance by Month
- EBITDA Margin Trend
- OPEX vs Budget
- Cost Structure (COGS vs OPEX)
